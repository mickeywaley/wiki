淘宝店铺工作细分下
----
--  天猫店铺

1.筛选所有顺丰包邮的打单。

2.筛选所有敏星千兰的登记报货（后面不定时刷新，就有登记报货，截止到下午5点）。

3.按快捷筛选： 数量1-1，数量1-2，数量3-4，重置查询（就是取消筛选了）打单。

-- 淘宝店铺

1.按快捷筛选： 数量1-1，数量1-2，数量3-4，重置查询（就是取消筛选了）打单。

--名珠店铺（定制定订单需要登记表格报货）

1.打单 无需报货的：硅胶免焊(亿达报货)，免焊橱柜灯，COB包胶防水灯带，等等。

2.打单样品订单。

3.打单3米发货的订单。

3.打单剩余备注好的订单。

名珠打单注意事项
----------
1.先筛选把无需登记的打了。

2.在筛选把3米发货的了打单了（每单需登记到报货表）

3.打剩下的（每单需登记到报货表）

4.报货表登记表格内登记一个，就在TXT文档里面复制一份，准备分单报货用（直接表格内复制发到微信变文字）

5.报货核对注意事项，一波打单完毕后，快递单和表格内的用户名字一一对应核对一遍，

6.报货核对注意事项，然后把TXT文档和表格内登记的一一核对一遍（防止复制有遗漏） 

7.报货核对注意事项，代加工微信群用TXT文档内的登记内容按条报货一次。

8.报货核对注意事项，代加工微信群报货的名字和内容在和表格内一一核对一遍。

9.报货核对注意事项，核对表格内的报货密码和备注区域是否一致，一致后把这次报货的表格发代加工微信群，本次报货结束，以后每次有新报货都按此流程一一核对后报货。

10.有用户退款的，报货群内通知作废，表格内删除，并群内通知已删除，然后发最新的表格。

11.如果退款的代加工已经裁剪（并且是非常用型号的会通知已裁剪，可以带过来），这类的可以重新加表格内，并发信表格到群内。

12.当天有需要退货（主要是用户退回件，外观完好，不影响二次销售的）给代加工的，在表格下面备注好。并在群内报货，同事把更新的表格发群里。


配件打单注意事情
----
1.桌面新建一个空白的TXT文档。

2.选一个店铺，把售后发的未打单的补发信息全部复制到新建的TXT文档内，并在售后客服聊天界面恢复数字1，做标记间隔下，然后重新整理下，删除不必要的信息，只保留：用户ID，补发内容，补发地址。

3.复制用户ID，找到用户，剪切此用户的所有补发内容，粘贴到此用户的聊天窗口内，剪切或复制用户的地址信息到自由打印地址识别出，剪切或复制带用户ID的补发内容到自由打印规格出，保存订单。

4.根据补发内容选择合适的快递打单，并吧快递单号发给用户，例如:JT312581821**** 极兔补发单号，并在聊天窗口订单处点补发，输入补发的快递单号并发货（系统会系统推送补发信息卡片，方便用户自行查看物流信息，此补发订单不会考核，找用户最近的一个订单输入即可，提示风控的多数都是代拍的，地址和不大地址不一致，遇到就忽略，直接补发下一个）。

5.所有店铺都处理一边 包括微信群的（一般是当时打完第一个所有店铺单号的时候11点左右，处理一边补发订单，然后12点后再处理一次补发订单（中午补发订单截止处理到12点），之后有补发订单就不定时刷新处理下，下午补发订单截止处理到到6点）。


其他注意事项
------

1.邮费差价，安装费：直接无需物流发货

2.配件补发类，按正常出单处理，并吧单号发给用户（留言快递单号例如 JT312579857****  极兔单号）

3.配件补发类注意事项，我们这边发货的配件正常出单，面单上手写配件（防止放整灯给用户）

4.配件补发类注意事项，代发的配件出单后，面单上有价格的用油性笔涂掉，面单上手写配件（防止放整灯给用户）

5.订单提示：异常快递预警（极兔(百世)） 类的，更换其他快递发货，极兔发货了更换中通，中通也发不了的更换顺丰。

6.补发的配件分类摆放，分我们自己发的（放靠打印机一边），和鑫亮补发的（放显示器底座上）

7.有疑似抽检或打假的订单出单后，把ID和快递单给店长处理。

8.订单备注：开收据随货一起发，这类订单记得到开收据。

9.不能放一起打包出的订单，能拆单的都拆单发货，尽量让每个订单都有快递单号（让用户后台可以直接查看对应商品单号）

10.所有等通知发货（延期发货）的订单，看到就及时锁定订单，防止误发货。

11.所有加急的订单，订单上备注加急，上午的无需特殊处理，下午的及把单子给外面生产的发货（代发的及时群里报货加急订单，截止到下午5点）
